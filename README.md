# coteam-pipeline-demo

A tiny to-do list. It exists to try [coteam-pipeline](https://github.com/Tinghecui/coteam-pipeline)
on a real repository: issues labelled `pipeline` are picked up by an agent that opens a pull
request, a second agent reviews it, and low-risk changes merge on their own.

`npm test` runs the tests; `npm start` serves the page on http://localhost:3000.
